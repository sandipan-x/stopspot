# StopSpot

Stopping distance calculator: enter speed, reaction time and road condition to get reaction, braking and total stopping distance — with a road-strip visual and full speed chart. Free.

## Features
- Unit toggle (km/h / mph) with condition presets: dry, wet, snow, ice
- Reaction-time slider across alert / normal / tired / distracted scenarios
- Full 20–120 speed chart plus a 2-second-rule following-distance readout
